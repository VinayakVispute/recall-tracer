Recall Tracer · Dev A and Dev B plan

Lanes A (graph and data) and B (agent, MCP, API, deploy) from the Recall Tracer Build Plan, mapped onto the repo as it is after the Next.js move (commit 8fb19e3). Written Oct 17.

Decisions

Outbreak runs on the AI SDK agent

runOutbreak lives in src/agent/ai-agent.ts as a second ToolLoopAgent with the outbreak prompt. GET /outbreak/stream maps its tool calls and results onto the C3 TraceEvent SSE, so Dev C and the replay route see the same shape as the recall trace.

Hosting is Vercel plus an API host (Dev C)

Next.js in web/ deploys to Vercel with RECALL_API set. The Hono API ships as one container (Railway, Fly or Render) that seeds FalkorDB Cloud on boot. Replay needs no key.

Deadline as written

Sync 1 Oct 17 22:00. Sync 2 Oct 18 11:00. Freeze Oct 18 12:00. Submit 18:00. P1 starts only if every P0 is green by Sync 2.

db_ms comes from FalkorDB itself

Each query reads FalkorDB's own "internal execution time". An AsyncLocalStorage scope per tool call sums them, so no handler changes its return type and every MCP result gains db_ms and queries.

Plan drift to fix with the team

  • pathsLanes C and D name web/src/App.tsx, pages/*, panels.tsx. The UI now lives in web/app/* and web/components/dashboard/*. The "split App.tsx into a router" item is done by the App Router already. Fixtures stay at web/fixtures/*.json.
  • deployThe Dockerfile still runs bun run build (now the Next build, whose deps are not installed) and start serves only the API. Dev C rewrites it as an API-only image.
  • seed valuesThe mockup case stores (ST-032, ST-045, …) and the L-117 and L-131 counts are mockup values. A2 picks case stores from the real generator's affected stores and writes the real ranking to expected.json. Dev C reads names from the fixture, never from the mockup.

Risks

  • SSE on VercelVercel rewrites proxy to an external API but can cut long streams. If /outbreak/stream or replay stalls, the browser calls the API host directly with CORS on.
  • FalkorDB Cloud authdb.ts has no username or password today. Dev C adds them. TLS may be needed on the free tier.
  • countsAdding cases changes node and edge totals in expected.json. The dashboard's "163 records" line reads the live count, so nothing hardcodes it.
